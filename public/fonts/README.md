# Brand fonts

These are the Figtree and Bricolage Grotesque Latin variable font assets already used by
`healthmatrix-doctor-dashboard` through `next/font/google`. They are self-hosted here so the
admin uses the same brand typography without requiring a Google Fonts request at build time.

Original cached assets:
- Figtree: `de42cfb9a3b980ae-s.p.woff2` (weights 300–900).
- Bricolage Grotesque: `9d5a263311222317-s.p.woff2` (weights 200–800).
